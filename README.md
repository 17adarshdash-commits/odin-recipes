# odin-recipes
Odin Recipes
A recipe website built as part of The Odin Project Foundations curriculum.
What it is
A simple multi-page recipe site with three recipes:

Lasagna
Chicken Biryani
Ice Cream

Each recipe page includes a description, ingredients list, and step-by-step instructions.
What I used

HTML5

What I learned

HTML document structure and boilerplate
Working with headings, paragraphs, and lists
Linking between pages using anchor tags
Adding images with alt text
Organizing a project with multiple HTML files

How to run it

Clone the repo:

bash   git clone https://github.com/17adarshdash-commits/odin-recipes.git

Open index.html in your browser

No installs needed. Pure HTML.
